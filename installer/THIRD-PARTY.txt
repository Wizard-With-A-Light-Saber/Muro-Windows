Muro for Windows: third-party components

Muro is a Windows port of Muro by MrRockySL (PolyForm Shield 1.0.0; see NOTICE.md). Wallpaper videos belong to
their original creators.

mpv (libmpv-2.dll) - LGPL v2.1 or later build
  Plays the wallpapers. Dynamically linked; replace libmpv-2.dll with another build to change it.
  Source and build scripts: https://github.com/mpv-player/mpv and https://github.com/zhongfly/mpv-winbuild
  (release 2026-11-25-d32c910be6, the mpv-dev-lgpl package).

FFmpeg (ffmpeg\ffmpeg.exe) - LGPL v2.1 or later build
  Run as a separate program to import videos, make 30 fps copies and lock screen stills.
  Source and build scripts: https://ffmpeg.org and https://github.com/zhongfly/mpv-winbuild
  (release 2026-11-25-d32c910be6, ffmpeg-lgpl-x86_64-git-c81e35cf2).

NAudio - MIT
  Measures the loudness of the sound your PC plays, for the audio effects. https://github.com/naudio/NAudio

Microsoft Edge WebView2 (Microsoft.Web.WebView2 SDK and the WebView2 runtime) - Microsoft Software License Terms
  Draws interactive wallpapers. The SDK is bundled; the runtime is part of Windows 11 or installed by Microsoft.
  https://developer.microsoft.com/microsoft-edge/webview2/

.NET 8 runtime and Windows App SDK (Microsoft): bundled so Muro runs without installing them. MIT and the
  Windows App SDK licence terms.
